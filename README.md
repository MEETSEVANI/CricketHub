# CricketHub

CricketHub is a web-based cricket match and player information management system.

## Project Purpose

CricketHub provides a centralized platform for users to search for cricket players and matches and view information stored in a relational database.

Registered users will be able to search for players and matches, view details, and manage favourite players and matches.

Administrators will be able to manage player records, match information, team lineups, match results, and player performance data.

## User Roles

### Registered User

- Register an account
- Log in and log out
- Search for players
- Search for matches
- View player details
- View upcoming and past matches
- Manage favourite players and matches

### Administrator

- Create, edit, and delete player records
- Create, edit, and delete match records
- Manage team lineups
- Manage match results
- Manage player performance data

## Technology

- React
- Vite
- Node.js
- Express
- PostgreSQL
- Git
- GitHub

## Planned Deployment

The project is planned to use:

- Render for web application hosting
- Supabase PostgreSQL for the relational database
- GitHub Actions for automated testing

## Scope Constraints

The project will not include:

- Live match updates
- Third-party cricket APIs
- Automated data collection
- Commentary features
- Fall-of-wickets breakdowns

Cricket data will be manually managed within the system.

## Development

The project is being developed incrementally across four capstone milestones, with functionality, testing, security, and deployment requirements implemented throughout development.
